# Student Performance Analytics System (MySQL)

## Setup Instructions

1. Install MySQL
2. Open MySQL Command Line or Workbench

## Run the project

### Option 1 (inside MySQL)
SOURCE C:/path/to/student_performance.sql;

### Option 2 (CMD)
mysql -u root -p < student_performance.sql

## What it does
- Creates database and tables
- Inserts sample data
- Runs analytical queries

## Features
- Student performance analysis
- Attendance tracking
- Placement eligibility filtering
